# Practice Map

This folder is organized by the kind of thinking each task trains.

- `algorithms`: classic algorithm practice grouped by topic.
- `async`: Promise utilities, queues, retries, timeouts, and concurrency limits.
- `attempts`: older tries and repeat passes that are useful to compare later.
- `big-o`: notes and complexity drills.
- `courses`: material tied to a specific book, course, or guided curriculum.
- `data-structures`: caches and future structures like stacks, queues, trees, heaps, and graphs.
- `data-transformations`: everyday object/array reshaping tasks.
- `patterns`: reusable implementation patterns.
- `react`: hooks and React live-coding tasks.
- `typescript`: TS language and type-system exercises.
- `utilities`: standalone helpers that may eventually graduate into real reusable code.

Prefer keeping prompt, active implementation, and solution side by side:

```txt
example.task.md
example.ts
example.resolved.ts
```
